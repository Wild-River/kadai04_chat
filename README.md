# ①課題名

フォトマップ（Photo Map）

## ②課題内容（どんな作品か）

- 地図上の好きな場所にピンを立て、写真と紹介記事を投稿できる地図アプリです。<br>カフェやレストランなどカテゴリ別にピンを色分けし、お気に入りスポットを地図上に記録・共有できます。

## ③アプリのデプロイURL

https://wild-river.github.io/kadai04_chat/

## ④アプリのログイン用IDまたはPassword（ある場合）

- Googleアカウントでログイン（Firebase Authentication）
- ID: 各自のGoogleアカウント
- PW: 各自のGoogleアカウント

## ⑤工夫した点・こだわった点

- 地図をクリックするとスポットを投稿でき、写真・紹介文・営業時間などを登録できます。投稿データはFirestore、画像はFirebaseStorageに保存しています。
- スポットの編集画面には簡易的な「ブロックエディタ」を実装し、テキストと画像を自由な順番で組み合わせて記事を作れるようにしました（↑↓ボタンで並べ替え可能）。
- カテゴリ（カフェ・レストラン・エンタメ・映画館・ホテル・美術館）ごとにピンを色分けし、Google Fontsのアイコンを表示。カテゴリごとに表示のON/OFFも選べます。
- スポット詳細は、PCでは右から、スマホでは下からスライドインするパネルで表示。同じパネル内で表示と編集が切り替わるようにしました。
- 地図のスタイルをモノクロ⇔カラーで切り替えられるようにしました。

## ⑥難しかった点・次回トライしたいこと（又は機能）

- Google Maps APIの実装に苦労しました。（AIに聞きながらがんばりました）
- Viteでのビルド、GitHub Actionsによる自動デプロイにも初挑戦し、`git push` するだけでサイトが更新される仕組みを構築しました。
- APIキーなどの秘密情報は `.env` ファイルで管理し、GitHubには公開しないよう `.gitignore` で除外。本番デプロイ時はGitHub Secretsに登録して、GitHub Actionsのビルド時に安全に読み込む仕組みにしました。
- 次回はスポットの検索機能の追加にチャレンジしたいです。
